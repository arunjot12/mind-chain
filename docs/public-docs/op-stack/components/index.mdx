This section gives every OP Stack component exactly one identity page — its
**hub** — so "where do I find docs for component X" always has the same
answer. Each hub follows the same
[skeleton](/op-stack/contribute/component-hub-template): what the component
is, who runs it, where to start, and where its guides, configuration
reference, releases, source, and spec live.

Components are grouped by the protocol layer they implement. The layers
themselves are defined in
[OP Stack components](/op-stack/protocol/components), which is the canonical
taxonomy; for how the components interact at runtime, see
[OP Stack architecture](/op-stack/architecture). For release history across
all components, see [Releases](/releases).

| This group | Implements the layer |
| --- | --- |
| Sequencing | Sequencing, Data Availability |
| Derivation & execution | Derivation, Execution |
| Settlement & proofs | Settlement |
| Deployment & infrastructure | Cuts across layers; Governance is served by contracts and processes rather than OP Stack services, so it has no component hub |

Hubs are shipping in reviewed batches. Components without a hub yet are
listed with their release history; their hub pages follow.
